# Privacy notice

Last updated: October 3, 2026

Kanji Quiz does not create user accounts and does not include analytics, advertisements, person-to-person chat, purchases, or tracking code.

## Data kept on the device

The game stores the following information in the browser's local storage:

- kanji mastery and mistakes;
- perfect-group awards and best scores;
- the next review time for each completed group;
- accessibility settings.

This information stays in the browser profile on the player's device and is not sent by the game. A player can erase all learning progress from the in-game Settings screen. Clearing the browser's site data also removes it.

## Controller input

When a player chooses **Connect Touchpad**, Chrome asks permission to access a selected Sony controller through WebHID. Button and touchpad coordinates are processed in the page to control the game and draw strokes. They are not recorded or transmitted. Chrome controls the device permission and may remember it for the same origin.

## Optional microphone answers

Microphone dictation is optional and is available only for Level 2 English-answer questions. Recognized words appear temporarily in the answer box and are checked automatically. The game does not save audio or dictated answers.

When a player presses **Voice answer** or the L3 shortcut, Chrome asks for microphone permission. After permission is granted, the game looks for an audio-input device whose name identifies a DualSense, Wireless Controller, PS5, or controller microphone. If one is available it is selected; otherwise Chrome's normal microphone is used.

The mascot does not accept conversation and the game does not send speech to an AI helper. Speech recognition is supplied by the browser or operating system and may be processed by that provider's speech service. The recognized answer is placed in the text box and checked automatically.

The mascot's ten question prompts and 30 encouragement/retry lines are fixed prerecorded clips in the downloaded game. When Chrome exposes a DualSense/PS5 audio-output device, the game asks the browser to play those clips through the controller speaker; otherwise it uses the device's normal speakers. No player speech is used to create those lines, and the clips do not require a network request after the game files are downloaded.

Players can stop dictation by pressing the microphone button or L3 again, leaving the quiz, closing the page, or revoking microphone permission in Chrome. Players should say only the short quiz answer and should not say personal information.

## Third-party data and code

The game includes KANJIDIC2-derived kanji data and the Kanji Canvas recognizer. Their notices are in `CREDITS.md` and `THIRD_PARTY_NOTICES.md`.
